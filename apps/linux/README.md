# SyncDeck for Linux and SteamOS

SyncDeck is the planned Linux and SteamOS peer in the SyncDroid-Mesh local-Wi-Fi network. It will remain an equal peer and consume the same shared protocol, synchronization decisions, fixtures, and desktop visual system as SyncDroid-Mesh, SyncTosh, and SyncDows.

Implementation will begin after SyncDows completes native Windows packaging and physical-device interoperability testing. Linux filesystem integration, secret storage, notifications, background services, removable storage, and distribution formats will remain platform-specific.
